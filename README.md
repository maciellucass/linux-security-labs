## Linux Security Labs

This repository contains hands-on labs focused on Linux system security, with emphasis on access control, user management and system hardening practices.

---

### Objective

Build practical experience in securing Linux environments by simulating real-world scenarios commonly found in enterprise and security operations contexts.

---

### Scope

The labs in this repository cover:

- User and group management  
- File and directory permissions  
- Access control and privilege separation  
- Authentication policies  
- System hardening fundamentals
